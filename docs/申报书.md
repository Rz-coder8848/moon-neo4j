# moon-neo4j 项目申报书

> MoonBit 九月黑松客 · 参赛项目申报材料

## 一、项目名称

**moon-neo4j** —— 纯 MoonBit 实现的 Neo4j 客户端：Bolt 协议 + PackStream 编解码 + HTTP 事务端点 + 类型化 Cypher 查询构建器

## 二、一句话简介

用 MoonBit 从零实现一个零依赖的 Neo4j 图数据库客户端，覆盖 Bolt 二进制协议、PackStream 序列化、HTTP 事务端点与类型化 Cypher 查询构建，全部协议层逻辑在无网络环境下通过 83 个测试验证。

## 三、选题背景与创新点

### 背景

- MoonBit 生态正处于高速成长期，标准库（core）目前**尚无任何网络 / socket / HTTP 客户端包**，也**没有任何数据库驱动**。
- 图数据库（Neo4j 及其 Bolt 协议）是主流的属性图 / 知识图谱基础设施，但 MoonBit 生态此前没有任何实现。

### 创新点（无重叠论证）

经对 [mooncakes.io](https://mooncakes.io) 与 GitHub 的检索，**截至申报时 MoonBit 生态不存在任何 Neo4j / Bolt / Cypher 相关的包**。本项目是 MoonBit 生态中的：

1. **第一个 PackStream 二进制编解码器**；
2. **第一个 Bolt 协议（握手 + 消息状态机 + 分块帧）实现**；
3. **第一个 Neo4j HTTP 事务端点客户端**；
4. **第一个类型化 Cypher 查询构建器**。

选题填补了 MoonBit 在「数据库驱动」方向的空白，具有明确的生态价值。

## 四、技术方案

### 分层架构

```
┌─────────────────────────────────────────────┐
│  demo.mbt          Matrix 电影图演示 / CLI   │
├─────────────────────────────────────────────┤
│  cypher.mbt        类型化 Cypher 查询构建器   │
│  transaction.mbt   显式事务（BEGIN/COMMIT…）  │
│  http.mbt          HTTP 事务端点编解码        │
├─────────────────────────────────────────────┤
│  session.mbt       Bolt 连接状态机           │
│  message.mbt       Bolt 消息编解码 + 分块帧    │
│  handshake.mbt     Bolt 握手（magic + 协商）  │
├─────────────────────────────────────────────┤
│  packstream.mbt    PackStream 值模型 + 编解码 │
│  stream.mbt        流式读写器                │
├─────────────────────────────────────────────┤
│  transport.mbt     Transport 抽象 + Mock     │
└─────────────────────────────────────────────┘
```

### 关键设计

1. **PackStream 值模型**：单一 `PackStreamValue` 枚举覆盖 `Null/Bool/Int/Float/Str/List/Map/Struct/Bytes`，Map 以有序 `(String, value)` 列表保存插入顺序，与线上字节流严格一致。实现全部 41 种标记字节（tiny/8/16/32/64 位的整数、字符串、列表、映射、结构体、字节数组）。

2. **Bolt 协议**：握手魔数 `0x60 0x60 0xB0 0x17` + 版本协商；消息签名（HELLO/RUN/BEGIN/COMMIT/ROLLBACK/PULL/RESET/SUCCESS/RECORD/FAILURE/IGNORED）；16 位大端分块帧（`0x0000` 终止）。服务端消息解析为类型化 `ServerMessage` 枚举。

3. **连接状态机**：`BoltConnection` 用 `Disconnected/Connected/Ready/Streaming/Failed/Closed` 六态严格约束生命周期，任何越序调用返回 `None` 而不是破坏协议。

4. **类型化 Cypher 构建器**：运行时值只能通过 `Query::param` 绑定，生成 `$pN` 参数引用并**带外**传输，从构造上杜绝 Cypher 注入。

5. **传输抽象**：`Transport` trait 抽象字节管道，`HttpClient` trait 抽象 HTTP POST。全部协议层逻辑对 `MockTransport` / `MockHttpClient` 测试，真实 socket/fetch 后端留待平台侧（MoonBit core 暂无网络包，需查官方文档）。

## 六、关键技术难点与解决

1. **PackStream 变长整数与标记边界**：通过逐字节判定 marker 区间，正确处理 tiny int 的符号扩展、`C8/C9/CA/CB` 四种定长整数、以及 `B0..BF` 结构体标记与 tag 字节的区分。

2. **MoonBit `while` 尾位置返回值**：`while` 在尾位置是「产出值」的表达式，需补 `nobreak` 分支（编译错误 `[4108]`），已在会话读取循环中正确处理。

3. **类型参数语法**：泛型自由函数为 `fn[T] name`（而非 `fn name[T]`），泛型方法为 `fn[T] Type::method`，已全部对齐官方语法。

4. **名称冲突**：自定义 `PackStreamValue::Map` 变体遮蔽内置 `Map` 类型，通过 `@builtin.Map` 全限定名消歧（参考 core 中 `@builtin.Bytes` 等用法）。

5. **测试完备性**：为验证协议字节级正确性，对每个 PackStream 标记、每条 Bolt 消息、每个状态转移都写了白盒测试；黑盒测试从外部消费者视角驱动公共 API。

## 八、使用示例

```moonbit
// 类型化构建器 + 会话 + 事务
let q = Query::new()
let title = q.param(PackStreamValue::str("The Matrix"))
q.match_("(p:Person)-[:ACTED_IN]->(m:Movie)")
q.where_("m.title = " + title)
q.return_("p.name")
q.order_by("p.name")
let (cypher, params) = q.build()

let conn = BoltConnection::new(transport)
let _ = conn.handshake([bolt_version(5, 1, 0)])
let _ = conn.authenticate([("user_agent", PackStreamValue::str("moon-neo4j/0.1"))])
let rows = conn.run_query(cypher, params)
```
